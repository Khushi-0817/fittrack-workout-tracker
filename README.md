# 🏋️ FitTrack – MERN Workout Tracker

A modern full-stack fitness tracking web application built using the **MERN Stack**. FitTrack enables users to securely register, log in, and manage their personal workouts through an intuitive and responsive dashboard.

📂 **GitHub Repository:** https://github.com/Khushi-0817/fittrack-workout-tracker
